# PDF Editor プロジェクト仕様書

## 概要
シンプルなデスクトップPDF編集ツール。
複数のPDFファイルを読み込み、ページ単位で柔軟に編集できることを目的とする。
UIは極力シンプルに保つ。

## 対象プラットフォーム
- デスクトップアプリケーション（Windows優先、将来的にmacOS/Linux対応も検討）

## 機能要件（実装済み）

### 1. PDFファイル操作
- 複数PDFファイルの同時読み込み
- Markdownファイルの読み込み（`.md` / `.markdown`、1ファイル表示）
- 現在の状態を1つのPDFとして保存（連結＋全編集の反映）
- 選択ページを新しいPDFとして分割保存（切り出し）
- ページをPNG/JPG画像としてエクスポート（形式・DPI・JPEG画質・接頭辞・フォルダ指定）
  - サムネイル右クリックで「PDFを切り出し」「画像を切り出し」を選択式で起動
  - デフォルトの保存先は選択ページのオリジナルPDFと同じ場所
- ページ単位での並び替え（QTreeWidgetによるドラッグ＆ドロップ、ファイル間移動対応）
- ページごとの回転（+90° / -90° / 180° の3ボタン）
- 個別PDFファイルのクローズ（サムネイルのファイルヘッダ右クリック → 「閉じる」）

### 2. ページ編集機能
- ファイルごとにグループ化されたサムネイルツリー（折りたたみ可能）
- ドラッグ＆ドロップによるページ移動（ファイル間移動対応）
- ヘッダー＆フッターの挿入（詳細は下記「ヘッダー/フッター仕様」を参照）
- プレビューエリア
  - マウスホイールによる拡大縮小
  - 右クリックドラッグによるパン
  - 縦横スクロールバー
  - ページ選択時に横幅フィット表示
- Markdownプレビュー
  - Mermaid コードブロックを図として表示
  - LaTeX 形式の数式（インライン / ブロック）を表示
  - 相対パス画像・リンクの解決に対応
  - 表示内容を PDF として保存可能
  - Mermaid / MathJax はアプリ同梱資産を利用し、オフライン環境でも描画可能

### 3. UI / 操作性
- 上部アイコンツールバー（カスタム生成アイコン + ツールチップ）
- サムネイルサイズ切替（小 / 中 / 大）、切替時にスプリッター幅も自動調整
- 左側：ファイル別サムネイルツリー（複数選択対応：Ctrl/Shiftクリック）
- 右側：プレビュー
- 左右ペインの境界線をドラッグしてサムネイル列幅を自由に調整可能（QSplitter）
- サムネイル右クリックメニュー：
  - ファイルヘッダ右クリック： 「閉じる」
  - ページ右クリック： 「PDFを切り出し」 / 「画像を切り出し (PNG/JPG)」 を選択式で呼び出し
  - デフォルト保存場所は各ページの元PDFファイルと同じディレクトリ

### 4. その他
- 編集内容の保存（新規PDFとして出力）

## UIレイアウト（現在）
- **上部**: アイコン中心のツールバー
- **左側**: ファイルごとにグループ化されたサムネイルツリー（QTreeWidget、折りたたみ可能、ドラッグ＆ドロップ対応）
- **右側**: 選択ページのプレビュー（ズーム、パン、スクロールバー、選択時fit-to-width）
- **左右境界**: QSplitterによるドラッグリサイズ対応

## ヘッダー/フッター仕様
専用ダイアログ（`HeaderFooterDialog`）で設定する。設定値はセッション中記憶される。

### ヘッダー
- 有効/無効チェックボックス
- テキスト入力
- 位置選択: 左 / 中央 / 右

### フッター ― ページ番号
- 有効/無効チェックボックス（`- N / M -` 形式）
- 位置選択: 左 / 中央 / 右

### フッター ― テキスト
- 有効/無効チェックボックス
- テキスト入力
- 位置選択: 左 / 中央 / 右

### 重なり防止
ページ番号とフッターテキストが両方有効な場合、別行に描画する（ページ番号を最下行、テキストをその上）。

### 削除
「削除」ボタンで各ページをディスクから再読み込みし、挿入されたテキストを消去する。ユーザーが設定した回転は保持される。

### ルール
- 空のフィールドは挿入しない（チェックあり・テキスト空＝何もしない）
- 一度適用したテキストは PDF のページ内容に直接書き込まれる（削除機能で元に戻せる）

## サムネイルツリーの仕様詳細
- ファイルヘッダー行：テキスト1行＋上下0.5行パディング（コンパクト表示）
- ページサムネイル：固定幅キャンバス（左右1pxマージン）＋ページ番号ラベル（下部）
  - 縦長ページ：キャンバス高 = 画像高 + ラベル高
  - 横長ページ：キャンバス高 = 実際の縮小後画像高 + ラベル高（余白なし）
- 折りたたみ状態はドラッグ＆ドロップ後も保持される
- 折りたたまれたファイル内のページは自動展開されない
- 展開ボタン（▶）はインデント領域に描画。Qt の `rootIsDecorated=True` の都合で子アイテムのインデントは `2 × indent_px` になるため、パネル幅はこれを考慮して計算する

## パフォーマンス
- サムネイル生成は `(page_id, max_size, rotation)` をキーにキャッシュ。並び替え後の再描画はほぼ瞬時
- `get_thumbnail_pixmap` はスケール係数を一発計算して1回だけレンダリング（旧実装は最大2回）
- 回転・ヘッダー/フッター適用・全ページ閉じ時にキャッシュを適切に無効化

## 技術スタック
- **言語**: Python 3.12+
- **GUI**: PySide6 (Qt6)
- **PDF処理**: PyMuPDF (fitz)
- **画像処理**: Pillow
- **配布**: PyInstaller（予定）

優先観点: 開発速度、PDF操作の強力さ、クロスプラットフォーム性、単一exe配布のしやすさ

## 非機能要件
- UIは極力シンプルに保つ
- 操作は直感的（特にドラッグ＆ドロップ）
- 初回起動時の学習コストを低くする
