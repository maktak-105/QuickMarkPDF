# 結果報告: PDF編集コア機能の見直し・改善（v1.0）

対応する計画書: [2026-08-18_PDF編集コア機能改善_v1.1.md](2026-08-18_PDF編集コア機能改善_v1.1.md)（v1.1で承認）

全フェーズ（G→A→B→C→D→E→F）を実装順序通りに完了。各フェーズ終了時に自動テスト実行＋GUI起動確認（スクリーンショット含む）を実施。

## 実施内容

### Phase G: ヘッダー/フッター機能の全面削除
- `PDFManager`から`add_header_footer`/`remove_header_footer`/`_reload_pages_from_disk`/`_text_x`/`_HF_FONT`を削除
- `main_window.py`から`edit_header_footer`/`_refresh_after_hf`/`_hf_settings`/ツールバーボタン/`HeaderFooterDialog`のimportを削除
- `dialogs/header_footer_dialog.py`を削除、`dialogs/__init__.py`のexportからも除去
- 関連テスト5件を削除
- `documents/spec.md`/`environment.md`のHF関連記述を削除

### Phase A: 保存まわり
- `save_pdf`の失敗時フィードバック欠如を修正（`QMessageBox.warning`追加）
- `PDFManager.overwrite_source()`を新設：一時ファイルに保存→`close_all()`でロック解放→`Path.replace()`で安全に置換→再読み込み。失敗時は元ファイル非破壊
- `save_pdf()`実行時、単一ファイルのみ開いている場合に「上書き保存」/「新規で保存」/「キャンセル」の選択ダイアログを表示。複数ファイル時は従来通り「名前を付けて保存」のみ
- 上書き保存で実際に`Permission denied`が起きるケース（開いたままのファイルへの上書き）を実機再現の上、`overwrite_source`で解消したことをテストで確認

### Phase B: 編集操作の拡充
- `rotate_current_page`を複数選択対応に変更（`PDFManager.rotate_pages`新設）
- `PDFManager.delete_pages(indices)`新設。Deleteキー＋右クリックメニューから呼び出し可能に
- パスワード付きPDF対応：`PDFDocument.open()`が`needs_pass`を検知し`LoadResult.password_required`で報告。UIは`QInputDialog`でパスワードを最大3回試行、失敗ファイルは明示的にリスト表示

### Phase C: Undo機能
- `PDFManager`に軽量スナップショット方式のUndoスタック（上限20件）を実装
- 対象：並び替え・回転（複数ページ一括で1ステップ）・ページ削除・ファイルクローズ
- **バグ発見→修正**：`fitz.Page`オブジェクトはミュータブルなため、リスト参照を戻すだけでは回転が復元されないことが実装中に判明。各ページの回転値を明示的に記録・再適用する方式に修正（テストで再現・検証済み）
- ファイルクローズのUndoは、そのファイルをディスクから再読み込みして再挿入する特殊処理（クローズ前の未保存編集は復元されない、既知の制限）
- `close_all()`実行時にUndo履歴を自動クリア（ページオブジェクトが無効化されるため）
- Ctrl+Zにバインド

### Phase D: ドラッグ&ドロップの信頼性修正
- ページ項目から`Qt.ItemIsDropEnabled`を除去（ファイルヘッダーのみドロップ受付）
- Qt標準の`InternalMove`（`super().dropEvent()`への委譲）をやめ、`_insert_parent`/`_insert_child_index`から自前で新しい順序を計算する方式に全面書き換え
- 「同一ファイル内でも一度入れ替えたら戻せない」という主訴を、`_compute_new_order`の直接テストで再現・修正確認
- ファイルをまたぐドラッグも、保存順序（フラット順）には正しく反映されることを確認（ツリー表示のグループ分けは元ファイル基準のまま、計画通りの既知の制限）

### Phase E: UI整理
- 「連結」ボタンを削除（「保存」と同一機能だったため）
- サムネイルサイズボタン（小/中/大）を`QActionGroup`で排他制御し、選択中を視覚的に表示
- エクスポート設定（形式/DPI/JPEG画質）をセッション中記憶するよう`ExportDialog`に`initial`引数を追加
- サムネイル右クリックメニューに「回転」「このファイルを閉じる」を追加（削除は既にPhase Bで対応）
- Ctrl+O・Ctrl+Sのショートカット追加（Delete・Ctrl+Zは既にPhase B/Cで対応）。矢印キーでのサムネイル移動はQTreeWidget標準機能で動作することを確認、追加実装は不要と判断
- `QSettings`でウィンドウの位置・サイズ、最後に使ったフォルダ、最後に使ったサムネイルサイズを起動時復元・終了時保存する仕組みを追加

### Phase F: 安全性修正
- `_confirm_discard_pdf_changes()`ヘルパーを新設し、`closeEvent`と`_load_markdown_document`の両方から呼び出す形にリファクタ
- PDF編集中（未保存の変更あり）にMarkdownファイルを開こうとすると確認ダイアログが出るように修正（従来は無条件に`pdf_manager.close_all()`が呼ばれ、無確認で破棄されていた）

## 検証結果

- **自動テスト: 32件、全てPASS**（新規追加分：D&D計算ロジック3件、Undo7件、上書き保存2件、パスワード3件、ページ削除2件、未保存確認3件など）
- 各フェーズ終了時に`python main.py`での起動確認＋スクリーンショット目視確認を実施し、いずれもエラーなし
- 「上書き保存で何も起きない」問題は`Permission denied`エラーを実際に再現した上で`overwrite_source()`により解消したことを確認
- 「回転のUndoが効かない」という実装中に見つけた不具合は、原因（`fitz.Page`のミュータブル性）を特定し修正、再発防止のリグレッションテストを追加
- 「D&Dが運任せ」の主訴は、根本原因（Qt標準InternalMoveとの二重処理）を特定し、直接のテストで同一シナリオ（1P⇔2P入れ替え→戻す）が正しく動作することを確認
