### WebView2 GUI

場所: `core/webview2/`、`ui/`

- C++ Win32ホストからWebView2を起動
- `WebView2Loader.dll`をRelease出力へコピー
- HTML/CSS/JavaScript UIを表示
- WebMessage APIでJavaScriptとC++を相互接続
- ネイティブPDFファイル選択ダイアログ

場所: `core/native/pdf_backend.h/.cpp`

- `PdfBackend::inspect(path)` APIを追加
- 現在はPDFバイナリ内の `/Type /Page` を数える暫定検査
- 圧縮PDF、暗号化PDF、保存、画像化には未対応
- 正式なMuPDFまたはPDFium等へAPI境界を維持して差し替える

## 開発環境

導入済み:

- CMake、MinGW、Visual Studio 2022 Build Tools、MSVC x64、Windows SDK
- WebView2 SDK 1.0.2903.40（`third_party/webview2/`、Git管理外）
- WebView2 Runtime（実行環境側で必要）

別環境でSDKを取得:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/fetch_webview2_sdk.ps1
```

## ビルド・テスト

```powershell
cmake -G "Visual Studio 17 2022" -A x64 -S core/webview2 -B core/webview2/build
cmake --build core/webview2/build --config Release
Start-Process .\core\webview2\build\Release\QuickMarkPDF_webview.exe
```

```powershell
cmake -G "MinGW Makefiles" -S core/native -B core/native/build
cmake --build core/native/build --config Release
ctest --test-dir core/native/build --output-on-failure
```

```powershell
$env:PYTHONPATH='python'
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Pythonテストは37件PASSが基準。PySide6終了時にWindows固有の`-1073741819`が返る場合があり、CIでは許容している。

- WebView2全面GUIへ方針変更済み。Qt Widgetsへ戻さない。

- PDFエンジンのライセンス確認前に配布用EXEへ組み込まない。

- 現時点は初期段階であり、完成版とは扱わない。
