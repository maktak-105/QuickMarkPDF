作成日: 2026-08-20
前提: [`plans/2026-08-19_C++WebView2UI層_結果_v1.0.md`](2026-08-19_C++WebView2UI層_結果_v1.0.md)の残課題への対応。ユーザーより「次に進めてくれ、テスト、文書更新、GITは適時やること」との指示。

## 1. 目的

前回の結果ドキュメントに記録した残課題のうち、実機検証で潰せるものに対応する。

## 2. 対応する残課題

1. ステータスバーが回転・削除・元に戻す操作後に更新されない。
2. 保存・画像出力・ドラッグ並べ替えがUI経由で未検証。
3. 複数選択（Ctrl/Shift+クリック）が未実装。

## 3. 変更方針・検証方法

1. `post_document_state` の各呼び出し箇所に `post_status` を追加し、操作ごとのメッセージ（Python版に合わせた文言）を送る。
2. 実際にビルドし、CLI引数でPDFを開いた状態から、選択→回転→ドラッグ並べ替え→保存、を実際のマウス操作（PowerShellの`mouse_event`/`SendKeys`）で再現し、スクリーンショットで確認する。保存後は独立してPython(fitz)でファイル内容を検証する。
3. `app.js` にCtrl+クリック（トグル）・Shift+クリック（範囲選択）による複数選択を実装し、回転・削除の対象を選択ページ全体に変更する。実際にCtrl+クリックで2ページ選択し、一括回転が両方に反映されることをスクリーンショットで確認する。

## 4. 検証中に見つけた問題

- **実バグ**: `static/js/app.js` のドラッグ&ドロップ挿入位置計算が `const insertAt = dragFromIndex < index ? index : index;` という、条件に関わらず常に同じ値を返す無意味な三項演算子になっていた。正しくは `dragFromIndex < index ? index - 1 : index`（要素を取り除いた後の配列でのインデックスのずれを補正する必要がある）。
