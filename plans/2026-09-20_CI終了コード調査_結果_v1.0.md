# CIのQt終了コード調査 結果

## 原因
- GitHub ActionsのCIが`pytest`を直接起動していた。75件成功後にQt teardownが`0xC0000005`を返し、PowerShellの暗黙終了コードがステップを失敗させていた。
- リポジトリにはJUnit結果を確認し、全件成功時のQt teardown終了コードを処理する`proto/tests/run_tests.py`が既にあるが、CIで使われていなかった。

## 修正
- CIから既存の`proto/tests/run_tests.py`を呼び、ランナーの結果をステップ終了コードとして判定する。

## 検証
- GitHub Actions run `35494139526` 成功。prototype testsと後続native build/testsがすべて成功。
- 失敗時と同様にQt終了コードが出ても、JUnitに失敗・エラーがない結果を既存ランナーが成功として処理することをActions上で確認。
