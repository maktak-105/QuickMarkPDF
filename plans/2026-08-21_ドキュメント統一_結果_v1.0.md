## 1. 実施内容

出荷製品を C++17 + WebView2（`core/native/`）、Python を評価用プロトタイプ、
バージョンを v1.1.0、UI を日本語のみ、という正に揃えて、ユーザー向け・開発者向け
文書を一括更新した。`quick-app-template` の節構成に合わせ、実装していない機能
（言語切替、製品 CLI、公開済み GitHub Release、SHA-256）は主張していない。

1. **README.md / README_jp.md**: テンプレ構成（配布・GUI 使い方・CLI・ネイティブビルド・試作・ライセンス・第三者・免責・設計思想）。配布物に `vendor/` を追加。
2. **document/environment.md / environment_jp.md**: Python 先行・「仕様の正」だった記述を捨て、ネイティブ先行で全面書き直し。QA 数値を 27/27 PASS に更新。CI がまだ PyInstaller である残課題を明記。
3. **document/about.md / about_jp.md**: 表示言語、第三者、著作権行を追加。
4. **document/spec.md / spec_jp.md**: 表示言語、実際の WebMessage パラメータ、今後予定（ネストリスト・並列描画・製品 CLI・Release）を現状化。
5. **dist/documents/readme.txt / readme_jp.txt**: タイトル修正、`vendor/`、第三者、日本語免責。CRLF に統一。
6. **HISTORY / history.txt**: v1.1.0 に文書統一を追記。バージョン命名規則の例をテンプレに合わせた。
7. **LICENSE / LICENSE.txt / LICENSE_jp.txt**: `Copyright (c) 2026 maktak-105 (GitHub: https://github.com/maktak-105)`。
8. **CPP_PORT_POSTMORTEM.md**: 冒頭注記を「出荷版は C++。本文は一次失敗の記録」に更新。歴史本文は残した。
