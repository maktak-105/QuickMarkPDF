# Quickテンプレート標準化 実施結果 v1.0

実施日: 2026-08-21
対応する計画書: なし（ユーザーからの直接指示。他のQuick系アプリ4本の慣習を`quick-app-template`スキルに沿って調査した上で実施）

## 1. 実施内容

1. **アイコン刷新**: `core/native/QuickMarkPDF.ico`を新規デザインに置き換え。QuickFileCopyのSVGソース方式を踏襲し、`assets/QuickMarkPDF.svg`をソースとして残した上でPillowでラスタライズ（角丸ダーク背景＋白い文書ページ＋シアン→ブルーのアクセントバー＋シェブロン矢印）。
2. **ダークテーマ化**: `static/css/style.css`をQuickDiskBench/QuickFolderSize系のModern Dark / Glassmorphismテーマ（CSS変数体系: `--bg-primary`/`--accent-cyan`等、`#0a0c10`基調）へ全面置き換え。QuickFolderSizeの教訓に従いGoogle Fonts等の外部CDNには依存しない。レイアウトの寸法・座標（qa/baseline.json実測値に合わせた部分）は変更せず、色のみ置き換えた。PDFページ・Markdown本文などの「紙面」部分は白背景を維持し、chrome（メニュー・ツールバー・パネル）のみダーク化。
3. **ヘルプ機能追加**: メニューバーに「ヘルプ」を新設し、「使い方...」（操作説明・Markdownモード・キーボードショートカット一覧をまとめたモーダル）と「バージョン情報...」（バージョン・コンセプト・技術スタック・GitHubリンク）を追加。`templates/index.html`・`static/js/app.js`・`static/css/style.css`に実装。
4. **配布用readme.txt/readme_jp.txt刷新**: 旧内容（PyInstaller版・`_internal`フォルダ前提のプレースホルダー）を、C++/WebView2版の実際の配布物・起動方法・全機能の使い方に合わせて全面書き直し。改行はCRLFに統一。GitHub Releaseが未公開である旨を正直に明記。
5. **README.md/README_jp.md刷新**: 「C++移植は中止、Pythonが正」という古い前提（`CPP_PORT_POSTMORTEM.md`一度目の移植時の記述のまま）を、「C++/WebView2版が製品として出荷される版、Python版は開発中の評価用プロトタイプ」という現状に合わせて全面書き直し。テンプレートの10節構成＋「設計思想」セクション（QuickDiskBench実例の書きぶりに倣い、課題認識→3項目の太字見出し箇条書き）を採用。
6. **document/配下の整備**: 欠落していた`spec.md`・`spec_jp.md`（WebMessageプロトコル・機能一覧・画面構成を含む仕様書）・`about.md`・`about_jp.md`（バージョン・コンセプト・技術スタック・現在の位置づけ）を新規作成。`environment.md`/`environment_jp.md`は既に充実していたため変更なし。

その他、変更に伴い付随して実施:
- `HISTORY.md`/`HISTORY_jp.md`、`dist/documents/history.txt`/`history_jp.txt`にv0.1.0のまとめエントリを追加。
- `assets/quickmarkpdf-gui-en.png`/`-ja.png`/`-empty.png`をダークテーマの実機スクリーンショットに差し替え（Seleniumで実exeを操作して撮影。UIに言語切替機能が無いため英語版・日本語版は同一画像）。

## 3. 計画からの差分・ユーザー判断事項

作業前にユーザーへ2点確認し、以下の方針で実施した。

- **バージョン番号**: v0.1.0のまま維持（正式リリース番号への引き上げは見送り）。
- **ダークテーマとQA基盤の関係**: 見た目優先で進める方針を採用。現在の`static/css/style.css`は元々「Python/PySide6版と色・座標をピクセル単位で一致させる」ために作られており、`qa/`のQA基盤（`extract_cpp.py`のHSV測定等）がその一致を検証していた。今回の変更で**色の一致は意図的に崩れる**（構造・座標・挙動の一致は維持）。`qa/dashboard.html`のHSV列は今後Python版と異なる値になるが、これは既知の設計判断であり不具合ではない。

## 5. 残課題

- GitHub Releaseが未公開（タグ無し）。README/readme.txtには「ソースからビルドしてください」と明記した。
- `qa/extract_cpp.py`（色・座標のDOM測定、`baseline_cpp.json`生成）は未実行——environment.mdに「Known-unstable」と明記されている通り、WebDriver接続が不安定なため今回は見送った。ダークテーマ化により、次回実行時はHSV列がPython版と大きく異なる値になる（想定通り、要対応ではない）。
- CLI版（`QuickMarkPDF_cli.exe`）は元々ページモデルの動作確認用デモであり、実用的なコマンドラインオプション（QuickDiskBenchのような`--option value`群）は無いまま。README.md/readme.txtではその旨を正直に明記するに留めた。
- 前回のplanで挙がっていた「Python版とのピクセル単位の見た目比較」は、今回のテーマ変更により今後不要な検証項目になった（意図的な差分のため）。
