- バージョン: v1.1.0
- 出荷製品: `core/native/`（C++17 + WebView2）
- `python/`（PySide6）は開発中の挙動評価用プロトタイプ。配布しない
- UI 言語: 日本語のみ（言語切替なし）。英語 GUI スクリーンショットは同一画像

- GitHub Release は未公開。リンクは置くが、ソースビルドを案内する
